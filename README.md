# RA8P1-Edge-AI-Assistive-System

Real-time Edge AI assistive system on the **Renesas EK-RA8P1** using **μT-Kernel 3.0 (TRON RTOS)**, **YOLOX-Tiny INT8**, **Arm Ethos-U55 NPU**, and sensor integration for vision, motion, and environmental monitoring.

Submitted for the **TRON Programming Contest 2026**.
